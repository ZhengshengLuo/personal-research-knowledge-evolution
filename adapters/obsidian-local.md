# Obsidian 本地 Markdown 连接

Vault 目标由用户确认，本版本不硬编码修改任何真实路径。`init-vault` 只允许空白目标，预览默认不写；正文以可检索 Markdown + YAML + Wikilinks 表示。Paper/DeepReading 通过 SourceBundle 与实时 Understand 审计生成，额外证据 JSON 保存在 `.prke/evidence/UID/`。提交者只在独立预览及显式确认时运行，必须检查目标哈希并先备份。人工作品在 AI 管理标记外，不在更新中覆盖；人工改变管理区则停止、要求冲突确认。Zotero 不自动写，PDF 不复制到 Vault；关键图像的裁切、许可、核验与正式嵌入属于后续增量实施，不能以未核验的图片替代。
