# 给 Codex / Antigravity 的后续实机验收任务（不会自动执行）

> 本文是独立工作指令。先获得研究者对测试 Vault/资料和具体运行环境的授权；不要把用户的正式 Zotero 或 Vault 当测试沙盒。

## 目标

对 PRKE 1.6.0-integration-preview 按批准合同执行 W0–W7 剩余任务的**现场验收**。不擅自扩大权限、上传私有全文、修改科研结论或推送 GitHub。

## 实施顺序

1. 在新目录保留旧 1.5 ZIP，验 SHA；使用独立 Python/Conda 环境加载新 Skill。
2. 执行完整 unittest 和四个新 CLI 的 `doctor`；检查实际 `router_cli doctor`、各业务 doctor 与安装依赖。
3. S0 用实时科学问答，检验是否免创建工程文件且没有将相关当因果；记录全文回答及独立评估。
4. S1 对研究者批准使用的合法真实 PDF，核验渲染与实际视觉访问、图表真实内容、论文版本，按 Gold Set 作盲法评价。
5. S2/S3 通过宿主实际调用可用检索和 PDF 子 Agent；保存真实 provider 回执，测试“直接 SIFn 早响应不等于重建 SIF 全生命周期时点准确”，完成候选 Gap 的真实反证检索。
6. S4 只在新建的隔离测试 Vault 进行 Claim/Relation/Gap 处理和受控写入，检查人工作品保护、旧账本兼容和重复提交。
7. S5 用网络超时、断电模拟/进程终止、重复 action id、过期或冲突授权检查幂等恢复；对外部未知 job 先查询状态，不重复发起有副作用调用。
8. S6 用独立非遥感方法学论文开展完整评估；不能仅依赖遥感案例证明跨学科能力。
9. 配置不同 Windows 身份的文件访问权限，仅在研究者批准下对**测试 Vault**验证 Agent 账户直接写入被操作系统拒绝，可信提交进程可在独立授权下成功；所有结果记录系统帐号/ACL 证据，失败不得声称生产可信写入已通过。
10. 按 `docs/SCIENTIFIC_VALIDATION_PLAN.md` 执行 3–5 篇开发集和 10–20 篇冻结保留集；必要时记录真实 ≥24h soak，不可缩短后标 PASS。
