## S0–S6

S0 QUICK：直接科研问答，无强制任务目录；对 causal/associational 做正确区别。
S1 全文精读：原始文件版本、关键页图真实查看、作者结果与 Agent 推断分离。
S2 三篇 SIF 论文综合：产品类型与时间支持对齐；未测试的 onset/peak/recovery 不外推。
S3 Gap：最近已有研究、反证检索、可证伪假设；允许没有有效 Gap。
S4 知识更新：真实原始论文来源、稳定 ID、Claim 关系、Gap 历史和测试 Vault 受控提交。
S5 任务恢复：未知外部 job 不盲目重复；已提交状态不能重复执行。
S6 跨学科：至少一种非遥感研究设计，独立评价其方法学与科学推断。

## Gold Set

开发 3–5 篇，保留集 10–20 篇；包括真实论文与关键图表、人类核对的页/图与证据主张、真实方法局限、未见过的反例和跨学科材料。比较基础模型、v1.5.0-rc1、新 PRKE 与适用专项技能；固定模型/工具/来源条件，记录重复、消耗和科学错误。此前 Undermind 三篇 SIF 论文的子 Agent 审查只能当开发示例，**不能充当独立 Gold Set**。

## 阻断项

虚构已核验来源或视觉访问；假工具执行；重大未经证实的因果/创新性主张被自动确认；越权正式写入；恢复丢失人工内容/知识历史；有阻断错误仍声明通过。零阻断仅指测试范围。
