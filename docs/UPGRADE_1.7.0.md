# PRKE 1.7.0｜本次完整 Skill 升级记录

**源版本：** 1.6.0-integration-preview（完整安装包）  
**新版本：** 1.7.0-research-first-preview  
**定位：** 优化现有 Skill 的科研行为、证据检查和本地稳健性；不是宣告完成 G1–G3。

## 主要变化

1. **主入口重写。** `SKILL.md` 不再以 CLI 或内部工程状态为叙事中心；优先科学问题、证据、竞争解释、科研成果、知识修订。QUICK、RESEARCH、MANAGED 仍保留。
2. **四条业务路线重写。** Acquire 强调真实文献与反证覆盖；Understand 强调源 PDF 图像、时间支持与方法边界；Synthesize 强调可比性和非强制 Gap；Organize 强调知识复用、版本历史与科学审批。
3. **科学核心凝练。** Reasoning、Critic、Knowledge Evolution 形成一致的学术决策原则；新增 `source-to-claim.md` 明确原文到 Claim 的可审查路径和历史案例中出现的错误类型。
4. **Router 更清楚。** 意图理解、规划和模块选择均按科研成果而非工程任务数量组织；不再把“已注册协议”误写成“已实现真实工具调用”。
5. **本地执行改良。** Host Handoff JSON 独占创建不再依赖 Windows 可能受阻的硬链接；动作请求准备采用隔离暂存及目录提交，减少半成品任务；补充文件/请求回执校验和负面测试。
6. **科学关系校验改良。** 所有声明不可比的研究主张关系均暂缓；明确文献归属、外部目标与审查回执的可核验程度，不把填有标签当作已科学证明。
7. **正式资产与功能声明保守。** 本版本不会更改正式 Zotero、Obsidian、仓库远端或历史案例；保留原有模块文件、模板与测试。G1 宿主路由、G2 Gold Set、G3 可信身份和 Worker 尚待实机验收。

## 已知且未由本包解决的边界

- 宿主 Codex/Antigravity 的实际 Skill 注册与可用检索/PDF/子 Agent 能力无法在本隔离环境中验证；手工安装必须在目标宿主检查。
- Zotero 本地 API、Obsidian GUI 和 Windows ACL 在目标机器上未测试；不能自动授予真实审批权限。
- 全文图像像素审查需要真实视觉工具或独立审阅者；当前本地脚本不会自动验证视觉理解。
- 科研成果需要独立未见过的 Gold Set 评分和同模型/工具权限的对照；离线测试不能替代。
- 长期 Worker 与跨会话持续执行未部署。
- 原作者尚需独立决定项目 LICENSE；本次不会代替作者选择开源许可。

## 如何理解通过结果

本地测试成功仅表示源代码在该环境通过相应单元和回归测试。真实科研用例、来源可信度、科学推断和正式写入的验证等级应分别报告。见 `docs/CAPABILITY_MATRIX.md` 和 `docs/PRKE_FINAL_DESIGN_CONTRACT.md`。
