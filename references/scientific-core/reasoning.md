# Scientific Reasoning Core — 科学推理通用协议

**任务**：科研问题驱动，要求证据链与推断等级匹配；不是需要在用户面前逐条填满的模板。

## 研究问题与推断类型

- DESCRIPTIVE：研究对象是什么、发生了什么；注意总体、抽样、观测误差与时空范围。
- ASSOCIATIONAL：变量怎样共变；要求识别共同驱动、季节循环、条件化与选择偏差。
- PREDICTIVE：训练分布、泛化场景、数据泄漏、校准与外部验证；预测性能不等于机制。
- CAUSAL：定义干预/处理、对照、estimand、识别条件、混杂/中介/碰撞变量；时序条件关联与可干预效应有别。
- MECHANISTIC：独立过程证据、反事实或机制区分实验；与相关曲线一致不能单独证实过程。

## 推理协议（按需激活）

1. 定义问题、目标对象、科学变量和测量误差来源。
2. 确定时空支持、研究设计和目标 estimand；对照项必须可比。
3. 列出最有力的竞争性解释和足以区分它们的证据。
4. 实际获取并核验支撑主张的原始资料，标注哪些只在摘要中出现。
5. 给出保守但明确的科学结论，说明哪些条件会使该结论失效。
6. 如果值得推进，定义最小有辨别力的后续验证或反证任务；不为完成表格而强行创建研究 Gap。

## Claim–Evidence–Warrant–Boundary

对有实质科研影响的主张保留 Claim（可检验表述）、Evidence（可定位来源）、Warrant（为何该证据支持结论）、Boundary（研究条件与未知）。反证及同行不同方法只在相关时追加；不得使用未经核验的领域共识标签。

## 错误识别

不得把 p 值低当作效应强或因果识别；不得把共享训练样本视为独立验证；不得把观测时间支持与生态过程发生时刻混同；不得把未检出效应解释成确定不存在；不得将不同研究尺度上的结论强行投票。
