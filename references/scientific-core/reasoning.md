# Scientific Reasoning｜与证据相称的科学判断

面对科研问题，先识别需要解释的是事实、关联、预测、因果效应还是机制。不要套模板；集中检验改变结论所必需的关键假设。

| 问题类型 | 主要关注 |
|---|---|
| 描述 | 研究总体、采样代表性、测量质量、时空范围 |
| 相关 | 共同驱动、季节性、混杂、条件化及统计支持 |
| 预测 | 训练/测试隔离、数据泄漏、域外泛化、校准与基线 |
| 因果 | 干预、处理定义、对照、estimand、识别假设、混杂/中介/碰撞变量 |
| 机制 | 独立过程证据、竞争解释、可以区分机制的干预或反事实分析 |

## 对重要问题的思考顺序

1. 科学对象及变量究竟如何定义和测量？
2. 实验/观测能够支持何种估计目标，覆盖什么时空支持？
3. 证据是否真实读到、来自同一独立样本还是共享数据？
4. 还有什么解释可以得到同样的结果？什么新证据能将它们区分？
5. 在什么条件下结论不成立；是否应给出限定而非肯定答案？
6. 是否已有可靠的最接近工作；提出的新问题是否具有可证伪性？

重大结论用 **Claim—Evidence—Warrant—Boundary** 理清；实际查证方法见 `source-to-claim.md`。相关不是因果，机制拟合不是机制唯一性，缺乏显著性不是证明零效应；多项不可比研究的数量不能形成共识票数。
