# Scientific Critic — 自适应反方审查协议

## 触发与审查责任

LOW：必要来源核对；MODERATE：原文/图表的关键主张验证；HIGH：跨论文科学综合、重要方法比较、因果结论及 Research Gap；CRITICAL：改变研究者已确认的重要科学判断。高风险必须单独记录审查，具独立 Agent 条件时使用隔离上下文与原文访问；否则只能称 self-check。

## 审查程序

1. **先冻结主分析**：记录 claim、原始证据和成立边界，避免将结论事后改成不可证伪的模糊表述。
2. 从原文而非主 Agent 摘要出发，找最强反例、竞争性机制、选择/测量偏差及最近已有工作；不可编造反例。
3. 分开判断“本文未测试”“本文结果相反”“研究条件不可比”，不把 absent evidence 当作 evidence of absence。
4. 判断 SUPPORT / QUALIFY / DEFER / WITHDRAW，并提供可以改变判断的关键证据需求。
5. 出具带执行/来源与审查方法标签的记录，允许 `scripts/review_gate.py validate` 检查结构。`SELF_CHECK` 不得假装独立同行审查。

**完整例子**：若论文声称特定归一化轨道 SIF 在双周时间尺度早于绿度指标出现异常，审查是否被错误外推为全球连续重建 SIF 产品对极端事件起始、峰值、恢复的时点准确性。后者需要独立事件标准、产品对齐与时刻偏差统计；仅有“早期敏感”证据时应 QUALIFY 或 DEFER。

审查流程记录是证据质量控制，不保证科学主张的真实性，也不是科研者的自动批准。
