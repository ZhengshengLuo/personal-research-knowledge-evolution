# Scientific Critic｜主动寻找自己可能错在哪里

Scientific Critic 是按科学风险启用的**反方审查职责**，不默认为第五模块或假想的独立进程。

- **常规事实**：确认来源与基本语境即可。
- **关键论文结果**：回原文与实际 Figure 检查样本、定义、单位、统计量和边界。
- **科学争议、因果结论、重大方法选择、Research Gap**：冻结主分析，独立寻找最强反证与竞争性解释。
- **修改研究者已经确认的重要科学判断**：必须保留旧记录、提供差异和审查依据，并请求研究者决定。

审查应尽可能**先看原始证据，再看主分析解释**。不能因为两篇论文方向不同就叫矛盾；要检查是否研究同一估计目标、时空支持与独立样本。不能用别的尺度下的机制线索推定当前事件的实际主因。

输出应说明：支持（SUPPORT）、限定（QUALIFY）、暂缓（DEFER）或撤回（WITHDRAW）；哪条证据最有力、主要不确定性是什么、哪些可获取的新资料足以改变判断。

有真正的不同上下文 Agent 并能查原始资料时，保留其任务和来源访问回执；同一 Agent 自检时明确 `INDEPENDENT_REVIEW_NOT_PERFORMED`。`review_gate.py` 核对记录结构，不验证评价者身份或科学真值。原文到 Claim 的检查清单见 `source-to-claim.md`。
