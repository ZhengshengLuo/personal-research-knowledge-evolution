# 从原文到科学判断｜最低核验标准

科学审查不等同于核对 DOI 或填完来源字段。每条重要主张至少回答：**来源是否真实、原文实际说了什么、你的推断有没有越过证据？**

## 1. 来源完整性

确认论文身份、DOI/预印本版本、原始 PDF 或出版社页面、获取日期和实际可读范围。PDF SHA 与页面图片哈希只证明所用文件版本，不能证明图像被人或模型正确理解。引用作者原句须能在已访问版本中准确复核。

## 2. 主张与原文对应

给 Claim 记录：来源 Paper、文字定位/页码/图表、真正检验的变量和统计量、时空支持、研究设计、估计目标，以及是观察结果还是作者的机制解释。阅读图表时检查完整图像、坐标与单位、图例、分组、样本量、误差线/不确定性、图注、补充分析。不能只有 Figure 编号却无图像访问证明。

特别防止：小时结果写成日均；多日合并关联被解释为每日关系；R²、相关系数与斜率混用；相关被解释为因果；同数据评论被算作独立实验；叶片尺度的净同化被误记为生态系统 GPP。

## 3. 从证据到推断

每条重要科学关系都需要解释 **Warrant（为何有关）** 与 **Boundary（什么情况下不成立）**。直接检验、间接支持、方法风险、同数据再分析、模型机制可行性及不可比较的结果应有不同证据地位。保留竞争性解释和足以改变判断的下一项证据需求。

若全文仅部分获取、图像未看见、检索协议不完整或科学问题尚无判别证据，就清楚标注 PARTIAL / NOT_VERIFIED / UNCONFIRMED，而不是补写推断当作结论。

## 4. 科学反方审查与修订

重大争议/因果推断/Research Gap：冻结原始 Claim 和支持证据，由真正独立上下文的审查者直接查原始资料，区分观测、选择/测量误差、竞争机制及未检验问题；无独立条件则标为自检。新证据先更新候选关系与 Gap 事件，再提出修订，研究者确认重大正式认识。

## 5. 最简证据记录

```text
Claim：明确、可检验的表述
Source：论文版本 + 真实位置（PDF 物理页 / Figure / 表 / 数据记录）
Observed：实际看到的图表/文字/数据是什么
Support：对象、变量、尺度、估计量、设计、独立性
Warrant：为何这一来源支持、挑战或限定此 Claim
Boundary：限制、反证与未审材料
Status：来源访问 / 原文核验 / 科学审查 / 正式审批分别是什么状态
```

不要为每句常识建立结构化对象，只对重要结论、争议、方法决策和需要长期保存的认识执行完整核验。
