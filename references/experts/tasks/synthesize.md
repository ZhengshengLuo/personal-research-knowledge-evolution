# Synthesize Expert Protocol
**Purpose**: 从可比研究中得到有边界的科学认识、实质分歧与可检验问题。
**Triggers**: 文献综述、研究争议、交叉方法分析、Gap/Idea；**Exclude**: 某一论文单一数值检索。
**Decision Rules**: 对齐研究对象、measurement、estimand、时空支持、研究设计及共享观测。区分 direct support、indirect-only、not tested、contradictory、non-comparable。做 closest prior work / counterevidence search。重要因果结论与 Gap 由 Scientific Critic 审查，不强行生成 Gap。
**Evidence**: Claim+Evidence ID、原始引用、独立性组、研究局限、审查状态和反证结果；不能用统计票数代替证据质量。
**Failure Modes**: 不同 SIF 产品/时间尺度混作同一对象、缺少原文即宣布共识、无边界“首次”主张、把相关解释为因果机制。
**Deliverable/DoD**: 直达科研判断、可比性表、竞争解释、证据缺口、最小可证伪实验；如无可成立 Gap 也如实交付。
**Example**: 轨道 SIFn 在特定事件早期响应 ≠ 全球重建 CSIF/GOSIF 在全生命周期 timing fidelity 良好。
