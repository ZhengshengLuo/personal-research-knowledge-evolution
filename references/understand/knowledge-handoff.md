# Knowledge and Organize Handoff

Understand 只在库外任务暂存区生成 `PaperNoteDraft`、`ReadingRecord`、`FigureInventory`、`ClaimEvidenceMatrix`、`ReadingAudit` 和可选 `ComparisonMatrix`、HTML；**不执行 Zotero/Obsidian 正式写入**。

用户已选择任务级授权方案 A：用户明确授权指定批次与 Vault 目录后，未来 Organize 可对确认范围内经核验的笔记自动新增或安全增量更新，无须逐篇确认；遇到身份不明确、现有人工文本、同步冲突、覆盖/删除风险应阻止并申请裁决。没有 Organize 的实际接口时只能交付 `PENDING_ORGANIZE` 清单，不能说已入库。

既有原文、用户手写批注与模型生成判断分栏；以 DOI + 文献版本/本地文件哈希关联同一篇论文并保留审计历史。不可以删除或静默覆盖手工笔记。

笔记默认紧凑：元数据+类型+问题+方法/证据+局限+科研价值+阅读状态+原始论文链接，图表清单和长报告作为关联素材。HTML 为可选本地阅读视图，不需要自带外部 AI 或 API key。

现版任务授权信息可以记录，但 Router 目前禁止 P2/P3 正式写操作，待 Organize 实现并单独通过权限升级测试后才能落地。
