# PRKE 内置模板约定

- Paper Note：AI 和研究者快速理解；YAML 论文身份/来源/核验深度、科学问题、2–5项重要发现、批判性边界、科研价值与阅读链接。
- Deep Reading Note：正式 DEEP+COMPLETED 时生成，按四类论文侧重点组织完整研究逻辑、方法与公式、图表核验、Claim/证据和批判性评价。该模板不会声称已复现实验。
- Evidence Archive：结构化 JSON 索引，而不是第三份 Markdown；随阅读材料一起持久化，不复制原 PDF。
- Topic：支持领域知识和科学问题双形态；每新增10篇有证据相关论文触发后续 Synthesize，但 Synthesize 未实现时不得编造综合草稿。
- Method/Data：通用知识主笔记与版本，项目实践摘要在 Workspace，详细原件在科研项目目录。
- Idea：建议先于 Vault 外暂存，研究者确认后才入正式笔记。
- 无 00、01 数字目录；Academia Editorial + Research Studio 的视觉原则，可由后续 CSS Snippet 增强，**Markdown 可在无 CSS 下阅读**。
