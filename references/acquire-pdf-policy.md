# Acquire PDF 全文获取与人工交接协议

## 权限

自动：已有合法授权本地文件、实际可用的公开全文、具有真实授权的 Elsevier/Wiley/Springer 官方接口。权限不足、需要机构登录、验证码、图书馆网站、文献传递时一律 `NEEDS_MANUAL_REVIEW`，不自动操作学校账户或借用登录会话。对未经许可的镜像不建立自动通道。**下载到本地不等于获得对外传输许可**：默认本地优先，外部上传到 Undermind 等平台须独立核实许可并取得明确授权。

## 通道与优先级

1. 授权本地缓存或原文件的只读复用。
2. Undermind 工作区已明确提供的 PDF URL（必须检查访问/下载权限），以及 OA 官方机构仓库；该链接可能有有效期。
3. OpenAlex / Unpaywall 的实际 OA PDF URL 发现。返回 OA 候选不能证明链接可用或文件匹配。对于未列入经过审查的自动下载域名白名单的服务器，转人工审查后再加入允许来源。
4. Elsevier 官方 Article API，支持 PDF 时需真实访问权；Wiley 官方 TDM API，须具有有效 Token 和相应全文权利。
5. Springer Nature OA API 可用于 DOI、元数据、开放全文 JATS 及有时返回的 PDF URL；**不得把 JATS 自动命名为 PDF**，只有明确提供且允许访问的 PDF 才执行 PDF 下载。
6. 校园机构访问、学校图书馆、CARSI 和文献传递：全部转到 `manual_inbox` 人工工作流。

## 目录和处理

`<task_dir>/pdf/manual_inbox/`：用户放入由机构手动获取的 PDF；原件不删不动。
`<task_dir>/pdf/auto/`：自动取得待核验 PDF。
`<task_dir>/pdf/verified/`：首页论文标题与 DOI 均匹配时才保存只读来源副本；其他留待核验。
`<task_dir>/pdf/reports/`：不可变报告，包含原始文件路径、HASH、获取来源、匹配状态和未解决问题。

无 DOI 但首页标题高度吻合的文件只能 `PROBABLE`，需要额外人工检查；扫描版 PDF 无可提取首页文字不能靠文件头升级为已匹配；正文引用中的 DOI 也不可作为唯一匹配证明。当前代码的标题比对为严格且保守的工程启发式，**不是完全可靠的学术文献身份鉴定**。用户可在人工核对后另行提供确认记录；本版未实现人工确认提交程序，不得私自升级状态。

## 失败处理

HTTP 401/403：访问权不足；429：限速；重定向不可信：停止；HTML 错误页：不可冒充 PDF；PDF 大小超限/加密/扫描/身份冲突：标记待审。保留真实失败而不是自动切换到绕过授权的渠道。由 Router 根据任务预算决定下一轮是否再试，不提供无限重试。

## 与 Understand 的交接

候选记录 ID + 标准题录、PDF 文件路径、SHA-256、真实来源、已核验的身份状态、版本声明和待审原因；仅 `VERIFIED` 且许可允许的文件自动成为可交接 PDF。Acquire 可以建议阅读重点，但无法宣称原文方法和结论已经得到深度审查。
